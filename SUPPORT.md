# Support

Coding Tutor is a free, community-maintained project. There is no commercial support, paid tier, or guaranteed response time. No financial help, donations, or sponsorship are requested or accepted.

---

## How to get help

### 1. Read the README

Most setup, configuration, and usage questions are answered in [README.md](README.md).

### 2. Search existing issues

Someone may have already encountered the same problem:
[Browse issues](https://github.com/pypi-ahmad/Coding-Tutor/issues)

### 3. Open an issue

If you can't find an answer, open a new issue:
[Report a bug](https://github.com/pypi-ahmad/Coding-Tutor/issues/new?template=bug_report.md)
[Request a feature](https://github.com/pypi-ahmad/Coding-Tutor/issues/new?template=feature_request.md)

Please include:
- What you expected to happen.
- What actually happened (error messages, screenshots).
- Steps to reproduce the issue.
- Your operating system, Python version, and `uv --version` output.

---

## What this project does not provide

- Real-time support or a help desk
- Guarantees about AI model output accuracy or availability
- Support for dataset licenses beyond what is documented in the README
- Any commercial service or SLA
